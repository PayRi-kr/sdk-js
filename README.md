# PayRi SDK for JavaScript/TypeScript

PayRi 결제 API, 앱의 라이선스 확인, 서버 웹훅 검증을 위한 JavaScript·TypeScript SDK입니다.

자세한 사용법은 [JavaScript SDK 안내](https://docs.payri.kr/developers/sdk/js)와 [PayRi 개발자 문서](https://docs.payri.kr)를 참고해주세요.

## 패키지

| 패키지 | 설명 |
| --- | --- |
| [`@payri/sdk`](./packages/sdk) | 서버 API 클라이언트 `Payri`, 앱용 라이선스 클라이언트 `PayriLicensing`, 웹훅 검증과 처리를 제공합니다. |
